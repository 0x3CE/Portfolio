# /public/media

Images et vidéos d'Aj uniquement. Aucun asset repris d'un autre site.

Référencées depuis `content/projects.ts` via la clé `media`, avec un chemin
absolu qui commence par `/media/`.

Conseils :
- Image : format 16:10 environ, 1200px de large suffit (les cartes font 21rem).
- Vidéo : `.mp4`, muette, courte, **avec un poster** — il est obligatoire dans le type.
